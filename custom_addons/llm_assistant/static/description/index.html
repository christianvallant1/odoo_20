AI Assistant

Chat with a self-hosted LLM that looks up your Odoo data and proposes changes you confirm.

Two ways to talk to it

  • Odoo chat: write to AI Assistant in Discuss, like you write to OdooBot.
  • MCP: external AI apps connect to /llm_assistant/mcp with an API key of scope AI Assistant (MCP).

Safe by design

  • Every tool runs with the rights of the user the assistant works for.
  • Creating, changing and deleting records, or clicking buttons, only creates a proposal. Nothing happens until that user confirms it.
  • Credentials, API keys, access rights and technical settings are off limits, and you can block more models.

Works with your LLM server

Any server with an OpenAI-compatible chat API and tool calling: Ollama, vLLM, llama.cpp, LM Studio or a hosted provider. Set it up in Settings > General Settings > AI Assistant.

See README.md in the module folder for setup and security notes.
